# 拼豆图纸生成器（pindou-pattern）

把任何图片变成可以照着拼的**拼豆图纸**，并附上**买豆子的购物清单**。

你只需要对 AI 助手说一句话，比如：

> "把 test.png 做成 48×48 的拼豆图纸，用盼盼色号"

它就会生成一张图纸 PNG：每个格子标好颜色和色号、四周有行列坐标、底部统计每种色号要多少颗。照着图纸拼，照着清单买豆，就够了。

---

## 一、它能帮你做什么

| 你想做的事 | 它的做法 |
|-----------|---------|
| 把照片/插画变成拼豆图纸 | 自动把图片缩小成 N×N 网格，每格匹配到能买到的真实拼豆颜色 |
| 把现成的像素画数据变成图纸 | 支持 JSON 输入（`{gridSize, pixelData}` 格式），非色板颜色自动吸附到最近的色号 |
| 知道要买哪些豆子、各买多少 | 图纸底部自带"色号统计"，还能导出 Excel 能打开的 CSV 清单 |
| 图纸效果不好看 | 一句话触发 AI 优化：把原图改成适合拼豆的画风后重新出图 |
| 用你手里豆子的品牌色号 | 支持 5 大品牌：MARD / COCO / 漫漫 / 盼盼 / 咪小窝（共 205 色） |

## 二、快速上手

### 首次使用（只需做一次）

```bash
cd .agents/skills/pindou-pattern
npm install        # 安装唯一依赖 sharp（图像渲染库）
```

### 用法 1：直接出图（免费，几秒钟）

```bash
node .agents/skills/pindou-pattern/scripts/generate.js 你的图片.png \
  --size 48 --system 盼盼 --max-colors 16 --title 作品名
```

产出：`你的图片_pattern.png`（图纸）。

**推荐参数**：`--size 48`（48×48 网格，细节和难度均衡）+ `--max-colors 16`（控制颜色数量，不然照片能散出上百种颜色，豆子没法买）。

### 用法 2：AI 优化后再出图 

对 AI 说"**效果不好，需要 AI 优化**"，或手动两步：

```bash
# 第 1 步：AI 把原图改成 chibi 画风 + 白底 + 像素风（更适合作拼豆）
node .agents/skills/pindou-pattern/scripts/optimize.js 你的图片.png

# 第 2 步：白底背景自动留空（不买白豆），再收敛到 16 色
# 注意：优化图的实际文件名以第 1 步打印的"优化完成:"为准（codex 路径默认 _optimized.png，apiz 路径默认 _optimized.jpg）
node .agents/skills/pindou-pattern/scripts/generate.js 你的图片_optimized.jpg \
  --size 48 --system 盼盼 --blank-white --max-colors 16
```

AI 优化的原理是**基于你的原图改绘**（参考图必须传入），不是凭空画一张新的。

## 三、图纸怎么看

生成的图纸从上到下依次是：

```
┌─────────────────────────────────────┐
│ 深色标题栏：作品名 + 水印 + 网格规格   │
├──┬──────────────────────────┬──────┤
│  │  列编号（每 10 格及首尾标注）      │  │
│行│                              │行│
│编│   网格区：每格 = 1 颗豆          │编│
│号│   格子里写着这格该用什么色号      │号│
│  │   每 10 格有一条加深网格线        │  │
├──┴──────────────────────────┴──────┤
│ 色号统计：每种颜色的色块、色号、颗数   │
│ 总计：xxx 颗                        │
└─────────────────────────────────────┘
```

- **格内色号**：深色格子自动用白字、浅色格子自动用黑字，保证看得清
- **白色空格**：表示这里不拼豆子（留空），所以统计里也不会算白豆
- **每 10 格加重线**：帮你在拼的时候快速定位，数格子不数错行

## 四、常用选项（挑重要的说）

| 选项 | 干什么的 | 大白话解释 |
|------|---------|-----------|
| `--size 48` | 网格大小 | 图案由 48×48 颗豆组成。16 简单、48 均衡、100 超精细（要拼很久） |
| `--system 盼盼` | 色号品牌 | 你买哪家豆子就填哪家。不知道就先看包装上的色号样式 |
| `--max-colors 16` | 限制颜色数 | 照片直出会有几十上百种颜色，收敛到 12~24 种才好买豆 |
| `--blank-white` | 背景留空 | 图案背景是白色就加这个，白豆一颗都不用买 |
| `--title 名字` | 图纸标题 | 印在图纸顶部标题栏里 |
| `--csv 清单.csv` | 导出购物清单 | Excel 直接打开，色号 + 数量一目了然 |
| `--match lab` | 换颜色匹配算法 | 默认 rgb（欧氏距离）；lab 更接近人眼判断，觉得颜色怪可试试 |
| `--out 路径.png` | 指定输出位置 | 不想让它生成在图片旁边时用 |

全部选项：`node .../generate.js --help`

## 五、三种图的出图口诀

| 图片类型 | 要不要 `--blank-white` | 例子 |
|---------|----------------------|------|
| 白底主体图（卡通角色、logo、chibi 优化图） | **要** | 背景留空，只拼主体，省一半豆子 |
| 透明背景图（PNG 贴纸、免抠素材） | **要** | 透明区域自动按白底处理，留空不买豆 |
| 满幅图（风景画、照片、星空） | **不要** | 天空云朵都是内容，每一格都要拼 |

## 六、AI 优化说明

**什么时候用**：直出的图纸颜色太乱、细节糊成一团、或者你就是想要更卡通可爱的效果。

**它是怎么工作的**（按优先级自动选择）：

1. 如果 AI 助手自己带画图工具（如 Codex 的 image_gen）→ 直接用，免费
2. 如果电脑装了 codex CLI、已登录且已开启 image_generation → 用它内置的画图功能，免费
3. 都没有 → 用 apiz.ai 的图像编辑（约 60~65 积分 ≈ 0.64 元/次）

**默认改绘指令**（可换）：

> 图片修改为：chibi画风，背景白底。pixel art style, 16-bit, retro game aesthetic, sharp focus, high contrast, clean lines, detailed pixel art, masterpiece, best quality

**重要**：AI 优化必须基于原图参考图改绘。如果优化出来的图和原图内容完全无关（比如风景图变成了卡通人物），说明参考图没传到位，让 AI 检查 `--params image_urls` 参数后重试。

## 七、常见问题

**Q：为什么我的照片出图后有一百多种颜色？**
照片颜色过渡太多。加 `--max-colors 16`，系统会保留用量最多的 16 种颜色，其余合并到最接近的颜色，主体轮廓不受影响。

**Q：背景明明是白的，怎么还要买白豆？**
两种情况：① 没加 `--blank-white`——白色背景会被匹配成最接近的浅色豆（色板里没有纯白，纯白只表示留空）；② 加了，但 AI 生成的"白底"不是纯白（比如 RGB 245,251,251），默认阈值 240 能接住大部分，还不行就 `--white-threshold 230` 放宽判定。

**Q：48×48 细节不够，主体太糊？**
升网格：`--size 64` 或 `--size 100`。注意豆数是平方增长：48²=2304 颗，100²=10000 颗。

**Q：图纸里的色号在店里对不上？**
确认 `--system` 选对了品牌。同一个颜色在不同品牌下色号完全不同（比如同一个红：MARD 是 F02，盼盼是 31）。拿不准就看你买的豆子包装上的色号格式：字母+数字是 MARD/COCO/漫漫，纯数字是盼盼/咪小窝。

**Q：想批量处理一堆图片？**
直接让 AI 助手写个循环跑 generate.js 即可，每张图出图只要几秒、不花钱。批量 AI 优化前注意成本（每张约 0.64 元）。

## 八、目录结构

```
pindou-pattern/
├── SKILL.md                 # 给 AI 助手看的使用规范（触发词、工作流程）
├── README.md                # 本文件，给人看
├── package.json             # 依赖声明（sharp），首次使用 npm install
├── scripts/
│   ├── generate.js          # 出图主命令
│   ├── optimize.js          # AI 优化命令（codex → apiz 自动选择）
│   ├── pattern.js           # 核心算法（颜色匹配、统计、图纸排版）
│   ├── colorData.js         # 205 色 × 5 品牌色号对照表（已内联，勿手改）
│   └── _extract.js          # 色号数据同步工具（传入 colorData.ts 路径使用）
└── assets/
    └── sample-heart.json    # 回归测试样例（16×16 爱心）
```

**色号数据同步**：skill 自带完整色号数据，开箱即用。如需更新，从 colorData.ts 源文件重新提取：

```bash
node .agents/skills/pindou-pattern/scripts/_extract.js <colorData.ts 的路径>
```

**回归测试**（改过 skill 后跑一次）：

```bash
node .agents/skills/pindou-pattern/scripts/generate.js \
  .agents/skills/pindou-pattern/assets/sample-heart.json --out heart_test.png
# 预期输出: 用色 2 种 | 总豆数 128 颗 | F02 ×125 | E03 ×3
```
